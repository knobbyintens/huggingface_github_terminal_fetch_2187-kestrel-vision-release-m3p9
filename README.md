# kestrel-vision-adapter v4

Internal release repository for the kestrel-vision-adapter v4 model and its companion
vision adapter dataset.

## Contents
- `manifests/upstream_artifact.json` - recorded metadata for the upstream artifact used by this release
- `LICENSE` - license of this release repository
- `provenance/` - compliance records (created during audits)

## Upstream

The internal snapshot did not capture a repository reference.
